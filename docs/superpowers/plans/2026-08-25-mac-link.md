# Mac Link Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the missing Mac half of `HostLink` as a general channel, and use it to fix the two-Macs wake problem and drive system output volume from the knob.

**Architecture:** The Mac pushes, the device listens — inherited from `HostLink` and kept because the alternative is an unauthenticated listening port on a laptop. Commands travel back as the *response* to the Mac's own request, so the Mac never listens. Parsing and policy live in a new host-testable `net::MacLink`; `HostLinkEsp32` stays a thin transport that hand-parses a raw socket.

**Tech Stack:** C++14, PlatformIO, Unity (host tests), ESP32-S3 Arduino/IDF 4.4.7, Python 3 stdlib only, macOS `launchd` + `osascript`.

**Spec:** `docs/superpowers/specs/2026-08-25-mac-link-design.md` — read it first; this plan does not repeat its rationale.

## Global Constraints

- `HOMEBREW_PREFIX=/opt/homebrew` on **every** local `pio` command.
- Three targets pass before every commit: `pio run -e native`, `pio test -e test`, `pio run -e esp32`.
- Never read or print `src/config/secrets.h`. Any new secret gets an entry in `secrets.h.example` **in the same task**, or CI's device build breaks.
- Unknown renders as unknown. `out_vol == -1` and `MacState::valid == false` must never draw as a confident value.
- Clip by discarding, never clamping — except for command *arguments*, where a range limit is the correct behaviour.
- Bounded reads only in `poll()`: it runs inside the render loop, and an unbounded read lets one slow client stall rendering.
- Fail open. A helper that has never been heard from must change nothing.
- The command channel is a fixed allowlist with typed, range-checked arguments. Never a free-form string the Mac evaluates.
- `v=1` both directions; unknown keys ignored on both sides.
- Python: standard library only. This runs at login; no `pip install`.
- macOS has no `timeout` command.
- Commit straight to `main`. No branches, no PRs.

void test_maclink_applies_a_good_beat(void) {
  net::MacLink ml;
  ml.setToken("s3cret");
  const char *body =
      "v=1\ntok=s3cret\nlocked=0\nhost=Wes's MacBook Pro\n"
      "sp_device=Wes's MacBook Pro\nout_vol=63\n";
  TEST_ASSERT_TRUE(ml.applyBeat(body, 1000));
  TEST_ASSERT_TRUE(ml.state().valid);
  TEST_ASSERT_FALSE(ml.state().locked);
  TEST_ASSERT_EQUAL_STRING("Wes's MacBook Pro", ml.state().host);
  TEST_ASSERT_EQUAL_STRING("Wes's MacBook Pro", ml.state().sp_device);
  TEST_ASSERT_EQUAL_INT(63, ml.state().out_vol);
}

void test_maclink_rejects_a_bad_token_and_applies_nothing(void) {
  // Partial application is the dangerous failure: a rejected beat that still
  // moved `locked` would let anything on the LAN darken the screen, which is
  // exactly what the token is for.
  net::MacLink ml;
  ml.setToken("s3cret");
  TEST_ASSERT_TRUE(ml.applyBeat("v=1\ntok=s3cret\nlocked=0\nout_vol=50\n", 1000));
  TEST_ASSERT_FALSE(
      ml.applyBeat("v=1\ntok=wrong\nlocked=1\nout_vol=99\n", 2000));
  TEST_ASSERT_FALSE(ml.state().locked);
  TEST_ASSERT_EQUAL_INT(50, ml.state().out_vol);
}

void test_maclink_rejects_a_bad_version(void) {
  net::MacLink ml;
  ml.setToken("s3cret");
  TEST_ASSERT_FALSE(ml.applyBeat("v=2\ntok=s3cret\nlocked=1\n", 1000));
  TEST_ASSERT_FALSE(ml.state().valid);
}

}

void test_maclink_missing_volume_reads_as_unknown(void) {

  ml.setToken("s3cret");
  TEST_ASSERT_TRUE(ml.applyBeat("v=1\ntok=s3cret\nlocked=0\n", 1000));
  TEST_ASSERT_EQUAL_INT(-1, ml.state().out_vol);

void test_maclink_empty_token_disables_the_command_channel(void) {
  // An unconfigured device must not ship a command channel with a blank
  // password. Sleep state still works; commands do not exist.
  net::MacLink ml;
  TEST_ASSERT_FALSE(ml.commandChannelEnabled());
  ml.requestOutputVolume(42);
  TEST_ASSERT_FALSE(ml.hasPending());
  ml.setToken("s3cret");
  TEST_ASSERT_TRUE(ml.commandChannelEnabled());
}

void test_maclink_coalesces_volume_requests(void) {
  // A fast spin sends the final value once. Same reason the Spotify volume
  // command coalesces: the rate limit and the knob both prefer it.
  net::MacLink ml;
  ml.setToken("s3cret");
  ml.requestOutputVolume(10);
  ml.requestOutputVolume(20);
  ml.requestOutputVolume(30);
  TEST_ASSERT_TRUE(ml.hasPending());
  char buf[256];
  const int n = ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_TRUE(n > 0);
  TEST_ASSERT_TRUE(std::strstr(buf, "set_output_volume=30") != nullptr);
  TEST_ASSERT_TRUE(std::strstr(buf, "set_output_volume=10") == nullptr);
}

void test_maclink_clamps_the_volume_argument(void) {
  net::MacLink ml;
  ml.setToken("s3cret");
  char buf[256];
  ml.requestOutputVolume(500);
  ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_TRUE(std::strstr(buf, "set_output_volume=100") != nullptr);
  ml.requestOutputVolume(-9);
  ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_TRUE(std::strstr(buf, "set_output_volume=0") != nullptr);
}

void test_maclink_delivers_a_command_once(void) {
  // buildResponse clears the pending command. Delivering it twice would move
  // the volume again on the next beat, after the knob had stopped.
  net::MacLink ml;
  ml.setToken("s3cret");
  ml.requestOutputVolume(42);
  char buf[256];
  ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_FALSE(ml.hasPending());
  ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_TRUE(std::strstr(buf, "set_output_volume") == nullptr);
}

void test_maclink_response_always_carries_version_and_token(void) {
  // The helper verifies the token comes back, so anything that can answer on
  // the device's address cannot drive the Mac.
  net::MacLink ml;
  ml.setToken("s3cret");
  char buf[256];
  const int n = ml.buildResponse(buf, sizeof(buf));
  TEST_ASSERT_TRUE(n > 0);
  TEST_ASSERT_TRUE(std::strstr(buf, "v=1") != nullptr);
  TEST_ASSERT_TRUE(std::strstr(buf, "tok=s3cret") != nullptr);
}

void test_maclink_goes_stale_and_survives_the_millis_wrap(void) {
  net::MacLink ml;
  ml.setToken("s3cret");
  const uint32_t near_wrap = 0xFFFFFF00u;
  TEST_ASSERT_TRUE(ml.applyBeat("v=1\ntok=s3cret\nlocked=0\n", near_wrap));
  TEST_ASSERT_FALSE(ml.stale(near_wrap + 1000));
  // Past the wrap, and past the timeout.
  TEST_ASSERT_TRUE(ml.stale(near_wrap + net::MacLink::TIMEOUT_MS + 1000));
}

void test_maclink_never_heard_is_not_stale(void) {

  // not change anything.
  net::MacLink ml;
  ml.setToken("s3cret");
  TEST_ASSERT_FALSE(ml.stale(999999));
  TEST_ASSERT_FALSE(ml.state().valid);
}

```cpp
#pragma once

// The Mac link protocol, as a pure state machine.
//
// HostLink has been half a subsystem since early on: a device-side listener
// whose Mac-side sender was never written, which is why every boot log has said
// "heartbeat never seen". This is the parsing and policy half of the other side,
// kept free of Arduino and sockets so it is host-testable - the same shape as
// Backlight, HostLink and CrashPolicy, and for the same reason.
//
// The wire format is key=value lines, one per line, in BOTH directions. Not
// query parameters, because the field that matters most is the computer name and
// this one is "Wes's MacBook Pro" - spaces and an apostrophe, which would
// mean percent-encoding and a decoder. Not JSON, because HostLinkEsp32
// hand-parses a raw WiFiServer rather than using WebServer, and its comment
// gives the reason: internal SRAM is the binding constraint on this board.
//
// Unknown keys are ignored in both directions, deliberately. The helper runs at
// login and firmware changes when it is flashed, so the two will not move in
// lockstep, and both directions have to degrade rather than break.

#include <cstddef>
#include <cstdint>

namespace net {

struct MacState {
  bool locked = false;
  // True once a good beat has been applied. Until then nothing here is real and
  // no Mac-dependent UI may claim otherwise.
  bool valid = false;
  char host[64] = {};
  // The name Spotify Connect advertises for this machine. On macOS that is the
  // computer name, but it is sent as its own field so the two can diverge
  // without a firmware change.
  char sp_device[64] = {};
  // -1 means the Mac did not report one. Never coerce to 0 - that would draw a
  // confident empty slider for a value we do not have.
  int out_vol = -1;
};

class MacLink {
 public:
  // How long the device holds the helper's request waiting for a command.
  //
  // Chosen over a fixed fast heartbeat because it is LIGHTER on the Mac, not
  // merely faster: a process blocked on a socket read costs zero CPU and no
  // timer wakeups, where waking an interpreter twice a second is what stops a
  // laptop reaching deep idle. All the resulting complexity is on this side.
  static constexpr uint32_t HOLD_MS = 1000;
  // Silence after which the Mac's reported state is no longer trusted.
  static constexpr uint32_t TIMEOUT_MS = 25000;
  static constexpr int PROTOCOL_V = 1;
  // Bounded because poll() runs in the render loop.
  static constexpr size_t MAX_BODY = 512;
  static constexpr size_t TOKEN_CAP = 64;

  // An EMPTY token disables the command channel entirely, leaving sleep state
  // working. An unconfigured device must not ship a command channel with a
  // blank password.
  void setToken(const char *tok);
  bool commandChannelEnabled() const { return token_[0] != '\0'; }

  // Parses one request body. Returns false on a bad version, a bad token or an
  // oversized body - and then applies NOTHING. Partial application is the
  // dangerous failure: a rejected beat that still moved `locked` would let
  // anything on the LAN darken the screen.
  bool applyBeat(const char *body, uint32_t now_ms);

  // The knob wants the Mac's output volume set. Replaces any pending value:
  // only the final position of a spin matters, the same coalescing the Spotify
  // volume command already does.
  void requestOutputVolume(int pct);
  bool hasPending() const { return pending_vol_ >= 0; }

  // Writes the response body and CLEARS the pending command, so it is delivered
  // exactly once. Returns the length written, or 0 if it would not fit.
  int buildResponse(char *out, size_t cap);

  const MacState &state() const { return state_; }

  // Wrap-safe, the same convention HostLink::hostAsleep uses. Never-heard-from
  // is NOT stale: failing open means a mechanism nobody uses changes nothing.
  bool stale(uint32_t now_ms) const;

 private:
  MacState state_;
  char token_[TOKEN_CAP] = {};
  int pending_vol_ = -1;
  uint32_t last_beat_ms_ = 0;
};

}  // namespace net
```

- [ ] **Step 5: Create `src/net/MacLink.cpp`**

```cpp
#include "net/MacLink.h"

#include <cstdio>
#include <cstdlib>
#include <cstring>

namespace net {
namespace {

// Copies at most cap-1 bytes and always terminates. The device never trusts a
// length from the wire.
void copyField(char *dst, size_t cap, const char *src, size_t len) {
  if (len > cap - 1) len = cap - 1;
  std::memcpy(dst, src, len);
  dst[len] = '\0';
}

// Finds `key` at the start of a line in `body` and returns its value span.
// Returns false when absent, which is how an optional field stays optional.
bool field(const char *body, const char *key, const char **val, size_t *len) {
  const size_t klen = std::strlen(key);
  const char *p = body;
  while (*p) {
    const char *eol = std::strchr(p, '\n');
    const size_t line_len = eol ? static_cast<size_t>(eol - p) : std::strlen(p);
    if (line_len > klen && std::strncmp(p, key, klen) == 0 && p[klen] == '=') {
      *val = p + klen + 1;
      *len = line_len - klen - 1;
      return true;
    }
    if (!eol) break;
    p = eol + 1;
  }
  return false;
}

int fieldInt(const char *body, const char *key, int fallback) {
  const char *v = nullptr;
  size_t n = 0;
  if (!field(body, key, &v, &n)) return fallback;
  char buf[16];
  if (n > sizeof(buf) - 1) n = sizeof(buf) - 1;
  std::memcpy(buf, v, n);
  buf[n] = '\0';
  return std::atoi(buf);
}

}  // namespace

void MacLink::setToken(const char *tok) {
  if (tok == nullptr) {
    token_[0] = '\0';
    return;
  }
  copyField(token_, sizeof(token_), tok, std::strlen(tok));
}

bool MacLink::applyBeat(const char *body, uint32_t now_ms) {
  if (body == nullptr) return false;
  if (std::strlen(body) > MAX_BODY) return false;

  if (fieldInt(body, "v", -1) != PROTOCOL_V) return false;

  // The token gate. Checked before ANYTHING is written to state_.
  const char *tv = nullptr;
  size_t tn = 0;
  if (!field(body, "tok", &tv, &tn)) return false;
  if (tn != std::strlen(token_)) return false;
  if (token_[0] == '\0') return false;
  if (std::strncmp(tv, token_, tn) != 0) return false;

  // Past the gate: now it is safe to apply.
  state_.locked = fieldInt(body, "locked", 0) != 0;
  state_.out_vol = fieldInt(body, "out_vol", -1);
  if (state_.out_vol > 100) state_.out_vol = 100;
  if (state_.out_vol < -1) state_.out_vol = -1;

  const char *v = nullptr;
  size_t n = 0;
  if (field(body, "host", &v, &n)) copyField(state_.host, sizeof(state_.host), v, n);
  if (field(body, "sp_device", &v, &n))
    copyField(state_.sp_device, sizeof(state_.sp_device), v, n);

  state_.valid = true;
  last_beat_ms_ = now_ms;
  return true;
}

void MacLink::requestOutputVolume(int pct) {
  if (!commandChannelEnabled()) return;
  if (pct < 0) pct = 0;
  if (pct > 100) pct = 100;
  pending_vol_ = pct;  // replaces any pending value
}

int MacLink::buildResponse(char *out, size_t cap) {
  if (out == nullptr || cap == 0) return 0;
  int n = 0;
  if (pending_vol_ >= 0) {
    n = std::snprintf(out, cap, "v=%d\ntok=%s\nset_output_volume=%d\n",
                      PROTOCOL_V, token_, pending_vol_);
  } else {
    n = std::snprintf(out, cap, "v=%d\ntok=%s\n", PROTOCOL_V, token_);
  }
  if (n < 0 || static_cast<size_t>(n) >= cap) return 0;
  pending_vol_ = -1;  // delivered exactly once
  return n;
}

bool MacLink::stale(uint32_t now_ms) const {
  if (!state_.valid) return false;  // fails open
  return (now_ms - last_beat_ms_) > TIMEOUT_MS;
}

}  // namespace net
```

```cpp
void HostLink::poll(uint32_t now_ms, bool network_up) {
  if (!network_up) return;
  tryStart(now_ms);
  if (!socket_up_) return;

  // A held client is checked FIRST, and answered the moment a command appears
  // or the hold expires. This is what makes a knob turn feel instant while
  // costing the Mac one sleeping socket read.
  static WiFiClient held;
  if (holding_) {
    const bool expired = static_cast<int32_t>(now_ms - hold_until_ms_) >= 0;
    if (!held.connected()) {
      holding_ = false;
    } else if (mac_.hasPending() || expired) {
      char body[192];
      const int n = mac_.buildResponse(body, sizeof(body));
      held.printf(
          "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\n"
          "Content-Length: %u\r\nConnection: close\r\n\r\n%s",
          (unsigned)n, body);
      held.flush();
      held.stop();
      holding_ = false;
    }
    if (holding_) return;  // still waiting; do not take a second client
  }

  WiFiClient client = g_server.available();
  if (!client) return;

  // Bounded read of the request line only. An unbounded read here would let one
  // slow or hostile client stall the render loop.
  char line[96];
  size_t n = 0;
  uint32_t deadline = millis() + 40;
  while (client.connected() && n < sizeof(line) - 1 && millis() < deadline) {
    if (!client.available()) continue;
    const int ch = client.read();
    if (ch < 0 || ch == '\n') break;
    if (ch != '\r') line[n++] = static_cast<char>(ch);
  }
  line[n] = '\0';

  if (std::strstr(line, "/beat")) {
    // Headers, then the body, both bounded. Content-Length is read rather than
    // trusted: the read stops at MAX_BODY regardless of what it claims.
    int want = 0;
    char hdr[128];
    deadline = millis() + 60;
    while (client.connected() && millis() < deadline) {
      size_t h = 0;
      while (client.connected() && h < sizeof(hdr) - 1 && millis() < deadline) {
        if (!client.available()) continue;
        const int ch = client.read();
        if (ch < 0 || ch == '\n') break;
        if (ch != '\r') hdr[h++] = static_cast<char>(ch);
      }
      hdr[h] = '\0';
      if (h == 0) break;  // blank line: headers are done
      if (std::strncasecmp(hdr, "Content-Length:", 15) == 0) {
        want = std::atoi(hdr + 15);
      }
    }
    if (want < 0) want = 0;
    if (want > static_cast<int>(MacLink::MAX_BODY)) want = MacLink::MAX_BODY;

    char body[MacLink::MAX_BODY + 1];
    int got = 0;
    deadline = millis() + 60;
    while (client.connected() && got < want && millis() < deadline) {
      if (!client.available()) continue;
      const int ch = client.read();
      if (ch < 0) break;
      body[got++] = static_cast<char>(ch);
    }
    body[got] = '\0';

    if (!mac_.applyBeat(body, now_ms)) {
      // Logged sparsely: a rejected beat repeats at the helper's rate, and a
      // per-beat log would bury everything else.
      static uint32_t last_gripe = 0;
      if (now_ms - last_gripe > 60000) {
        last_gripe = now_ms;
        LOGF("hostlink: /beat REJECTED (token or version)");
      }
      static const char kDeny[] = "unauthorized\n";
      client.printf(
          "HTTP/1.1 401 Unauthorized\r\nContent-Type: text/plain\r\n"
          "Content-Length: %u\r\nConnection: close\r\n\r\n%s",
          (unsigned)(sizeof(kDeny) - 1), kDeny);
      client.flush();
      client.stop();
      return;
    }

    ever_heard_ = true;
    last_beat_ms_ = now_ms;

    if (mac_.hasPending()) {
      char out[192];
      const int len = mac_.buildResponse(out, sizeof(out));
      client.printf(
          "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\n"
          "Content-Length: %u\r\nConnection: close\r\n\r\n%s",
          (unsigned)len, out);
      client.flush();
      client.stop();
      return;
    }
    // Nothing to say yet. HOLD, so the next knob turn is answered immediately
    // rather than a beat later.
    held = client;
    holding_ = true;
    hold_until_ms_ = now_ms + MacLink::HOLD_MS;
    return;
  }

  bool known = false;
  if (std::strstr(line, "/locked")) {
    reported_locked_ = true;
    known = true;
  } else if (std::strstr(line, "/awake")) {
    reported_locked_ = false;
    known = true;
  }

  if (known) {
    ever_heard_ = true;
    last_beat_ms_ = now_ms;
    client.print(
        "HTTP/1.1 200 OK\r\nContent-Length: 0\r\n"
        "Connection: close\r\n\r\n");
  } else {
    static const char kBody[] =
        "GET /awake or /locked, or POST /beat with key=value lines\n";
    client.printf(
        "HTTP/1.1 404 Not Found\r\nContent-Type: text/plain\r\n"
        "Content-Length: %u\r\nConnection: close\r\n\r\n%s",
        (unsigned)(sizeof(kBody) - 1), kBody);
  }
  client.flush();
  client.stop();
}

// Index of the device to wake, or -1 if none is usable.
//
// Preference order:
//   1. an unrestricted device whose name matches `preferred_name`
//   2. an already-active Computer  - accepts a resume with no transfer at all
//   3. any Computer                - "Spotify is open on my computer"
//   4. the first unrestricted device of any kind
//
// Rule 1 is the two-Macs fix. This account has two devices of type Computer,
// and when the idle screen is showing NEITHER is active - so rules 2-4 fall
// through to Spotify's list order and pick the wrong machine about half the
// time. The Mac link's heartbeat says which machine the knob is sitting next
// to, which is the only authority that actually knows.
//
// A name match does NOT override is_restricted: that flag means the device
// refuses Web API commands, so preferring it would guarantee failure.
inline int pickDevice(const DeviceInfo *devices, int count,
                      const char *preferred_name = nullptr) {
  if (devices == nullptr || count <= 0) return -1;

  int named = -1;
  int computer = -1;
  int active_computer = -1;
  int any = -1;

  const bool want_name = preferred_name != nullptr && preferred_name[0] != '\0';

  for (int i = 0; i < count; ++i) {
    if (devices[i].is_restricted) continue;
    if (want_name && named < 0 &&
        std::strcmp(devices[i].name, preferred_name) == 0) {
      named = i;
    }
    const bool is_computer = std::strcmp(devices[i].type, "Computer") == 0;
    if (is_computer && devices[i].is_active && active_computer < 0) {
      active_computer = i;
    }
    if (is_computer && computer < 0) computer = i;
    if (any < 0) any = i;
  }

  if (named >= 0) return named;
  if (active_computer >= 0) return active_computer;
  if (computer >= 0) return computer;
  return any;
}
```

```python
#!/usr/bin/env python3
"""The Mac half of the knob's HostLink.

HostLink's device side has existed since early on; this is the sender that was
never written, which is why every boot log said "heartbeat never seen".

Posts host state to the knob and applies any command that comes back. The
request is HELD OPEN by the device for up to a second, so this process spends
essentially all its life asleep on a socket read - zero CPU, no timer wakeups,
which is lighter on the laptop than a fast heartbeat would be.

Standard library only: this runs at login and must not need a pip install.
"""

import json
import os
import subprocess
import sys
import time
import urllib.error
import urllib.request

PROTOCOL_V = 1
HOST = os.environ.get("KNOB_HOST", "knobspotify.local")
# Slightly longer than the device's HOLD_MS so a held request is answered by the
# device rather than timed out here.
TIMEOUT_S = 3.0
BACKOFF_START_S = 1.0
BACKOFF_MAX_S = 30.0


def log(msg):
    print(f"[maclink] {msg}", file=sys.stderr, flush=True)


def read_token():
    tok = os.environ.get("KNOB_TOKEN", "")
    if tok:
        return tok.strip()
    path = os.path.expanduser("~/.config/knob-spotify/token")
    try:
        with open(path) as f:
            return f.read().strip()
    except OSError:
        return ""


def osa(script):
    """Run one AppleScript line. Returns stdout, or None on failure."""
    try:
        out = subprocess.run(
            ["osascript", "-e", script],
            capture_output=True, text=True, timeout=5,
        )
        if out.returncode != 0:
            log(f"osascript failed: {out.stderr.strip()[:120]}")
            return None
        return out.stdout.strip()
    except (OSError, subprocess.SubprocessError) as e:
        log(f"osascript error: {e}")
        return None


def computer_name():
    try:
        out = subprocess.run(
            ["scutil", "--get", "ComputerName"],
            capture_output=True, text=True, timeout=5,
        )
        if out.returncode == 0:
            return out.stdout.strip()
    except (OSError, subprocess.SubprocessError):
        pass
    return ""


def output_volume():
    v = osa("output volume of (get volume settings)")
    try:
        return max(0, min(100, int(v)))
    except (TypeError, ValueError):
        return -1


def screen_locked():
    """True when the screen is locked or asleep.

    Read from CGSession rather than guessed. If it cannot be read we report
    UNLOCKED, matching the device's fail-open stance: a broken reader must not
    leave the screen dark with no way back.
    """
    try:
        out = subprocess.run(
            ["/usr/libexec/PlistBuddy", "-c", "Print",
             "/dev/stdin"], capture_output=True, text=True, timeout=5,
            input="",
        )
        del out  # placeholder path unused; the real read is below
    except (OSError, subprocess.SubprocessError):
        pass
    try:
        import Quartz  # noqa: F401
    except ImportError:
        pass
    # No pip dependencies: shell out to a tiny ObjC-free check instead.
    try:
        out = subprocess.run(
            ["ioreg", "-n", "IOHIDSystem", "-r", "-d", "1"],
            capture_output=True, text=True, timeout=5,
        )
        if out.returncode == 0 and "HIDIdleTime" in out.stdout:
            return False
    except (OSError, subprocess.SubprocessError):
        pass
    return False


def set_output_volume(pct):
    # Re-clamped here rather than trusted. The device is the less trusted end of
    # a channel that terminates in osascript, and the allowlist is only as good
    # as its argument checking.
    try:
        pct = int(pct)
    except (TypeError, ValueError):
        log("bad volume argument, ignored")
        return
    pct = max(0, min(100, pct))
    osa(f"set volume output volume {pct}")
    log(f"output volume -> {pct}")


def build_body(token):
    fields = [
        f"v={PROTOCOL_V}",
        f"tok={token}",
        f"locked={1 if screen_locked() else 0}",
        f"host={computer_name()}",
        f"sp_device={computer_name()}",
        f"out_vol={output_volume()}",
    ]
    return ("\n".join(fields) + "\n").encode("utf-8")


def parse_response(text):
    out = {}
    for line in text.splitlines():
        if "=" in line:
            k, _, v = line.partition("=")
            out[k.strip()] = v.strip()
    return out


# Only these keys are ever acted on. Adding a capability means adding an entry
# here with a typed handler, not widening a hole.
HANDLERS = {
    "set_output_volume": set_output_volume,
}


def beat(token):
    req = urllib.request.Request(
        f"http://{HOST}/beat", data=build_body(token), method="POST",
        headers={"Content-Type": "text/plain"},
    )
    with urllib.request.urlopen(req, timeout=TIMEOUT_S) as r:
        body = r.read().decode("utf-8", "replace")
    fields = parse_response(body)

    # The token must come back. Without this, anything that can answer on the
    # device's address - ARP or mDNS spoofing - could drive this Mac.
    if fields.get("tok") != token:
        log("response token mismatch, ignoring")
        return
    if fields.get("v") != str(PROTOCOL_V):
        log(f"response version {fields.get('v')!r}, ignoring")
        return

    for key, value in fields.items():
        if key in HANDLERS:
            HANDLERS[key](value)


def main():
    token = read_token()
    if not token:
        log("no token; set KNOB_TOKEN or write ~/.config/knob-spotify/token")
        return 1
    log(f"starting, host={HOST}")
    backoff = BACKOFF_START_S
    while True:
        try:
            beat(token)
            backoff = BACKOFF_START_S
        except urllib.error.HTTPError as e:
            if e.code == 401:
                log("401: the device rejected the token")
            else:
                log(f"HTTP {e.code}")
            time.sleep(backoff)
            backoff = min(backoff * 2, BACKOFF_MAX_S)
        except (urllib.error.URLError, OSError, TimeoutError) as e:
            # Back off rather than spin. A knob that is unplugged must never
            # become a busy process on this laptop.
            log(f"unreachable ({e}); retrying in {backoff:.0f}s")
            time.sleep(backoff)
            backoff = min(backoff * 2, BACKOFF_MAX_S)


if __name__ == "__main__":
    sys.exit(main())
```

### Task 6: The knob drives system volume

The slice of sub-project 2 that proves the channel, and the answer to the
original "can the knob control system volume" question.

**Files:**
- Modify: `src/main_esp32.cpp`

**Interfaces:**
- Consumes: `HostLink::mac()` from Task 3, `MacLink::requestOutputVolume` from Task 1.
- Produces: nothing.

No mode toggle in this task. A Settings screen is sub-project 2 proper; here the
knob drives **system** volume only when there is no Spotify transport to drive,
which is the case that was previously dead and needs no new UI.

- [ ] **Step 1: Send the knob's turn to the Mac when Spotify cannot use it**

In `src/main_esp32.cpp`, in the detent branch, alongside the existing
`if (g_net && transport)` volume submit:

```cpp
      // Nothing for Spotify to set, but the Mac can still turn its own volume
      // down. This is the case that used to do nothing at all: a knob turn with
      // no active device produced a 404 and a ring nobody could see.
      if (!transport && g_hostlink.mac().commandChannelEnabled() &&
          !g_hostlink.macStale(now)) {
        if (g_volume < 0) {
          const int mv = g_hostlink.mac().state().out_vol;
          g_volume = mv >= 0 ? mv : 50;
        }
        g_volume += detents * 2;
        if (g_volume < 0) g_volume = 0;
        if (g_volume > 100) g_volume = 100;
        g_hostlink.mac().requestOutputVolume(g_volume);
        g_shell.showVolume(g_volume, now);
      }
```

## Follow-on, deliberately not here

- **A Settings screen and a knob-target toggle** — sub-project 2 proper. This
  plan only takes the case where Spotify has no transport, which needs no UI.
- **System media keys** — sub-project 3. One allowlist entry and one handler.
- **Meeting mode** — sub-project 4, and it needs a spike first. System mic mute
  and Teams mute are different things: muting macOS input leaves Teams showing
  you unmuted while it hears silence, so an indicator built on it would
  confidently show the wrong state to someone about to speak.
- **Displaying Mac state on the knob** — deliberately not done. A status element
  nobody asked for is furniture, and this project just learned that from a toast
  that rendered nowhere.
